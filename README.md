## 🔬 项目简介

《不太正常的植物研究所》是一款基于 Python 的文字模拟与探索游戏。

玩家将扮演一名刚刚入职的植物研究员，在研究所中开展植物培育、杂交实验、遗传规律研究及日常管理工作。

这里没有直接向玩家公开的完整遗传规则表。你需要通过实验观察、杂交记录与数据分析，逐步理解植物性状背后的遗传机制。

与此同时，研究所似乎还有一些没有写进入职手册的秘密。

本项目主要面向 **AI Agent 玩家**设计，也欢迎人类玩家通过 Python 接口进行探索。

## 🌱 游戏特色

### 1. 植物培育与遗传实验

- 播种、照料、授粉、杂交与采种
- 观察植物表型及个体差异
- 设计实验，推断性状遗传规律
- 记录实验结果，追踪不同植物的表现

实验结果并不总会符合你的预期。

一次失败的杂交，也可能提供有价值的信息。

### 2. 研究所经营与日常探索

研究所设有种子库、四座温室、育苗室及组织培养室。

玩家可以管理植物、使用研究设施、与同事交流，并在日常工作中逐步接触研究所的其他事务。

植物不会因为你是新来的就停止生长。

同事也未必会主动告诉你所有事情。

### 3. 研究日志与科学发现

通过记录和比较不同实验结果，逐步建立属于自己的研究资料。

比起直接查看答案，本游戏更鼓励玩家提出假设、开展验证，并根据新证据修正判断。

### 4. 轻度悬疑与研究所怪谈

随着研究工作的推进，一些不寻常的现象可能逐渐进入研究员的视野。

请注意：

**不要将所有异常都当作实验误差。**

当然，也不要过早认定它们一定存在超自然原因。

## 💻 快速开始

### 环境要求

- Python 3
- 可以执行 Python 代码的本地环境或 AI Agent 运行环境

### 安装

获取项目中的 `greenhouse_lab.py`，将其放入 Python 工作目录。

进入 Python 交互环境后执行：

```python
import greenhouse_lab as gl

print(gl.cmd("help"))
```

### 开始游戏

```python
import greenhouse_lab as gl

# 查看游戏帮助
print(gl.cmd("help"))

# 查看当前状态
print(gl.cmd("status"))

# 与研究所成员交流、查看物品和植物
print(gl.cmd("talk wen; lots; plants"))

# 结束当天
print(gl.cmd("end"))
```

所有游戏操作均通过 `cmd()` 接口完成，执行后返回文字结果。

多条指令可以使用英文分号 `;` 连接，每次最多执行 10 条。

更多操作请以游戏内 `help` 输出为准。

## 💾 存档机制

游戏支持 JSON 自动存档。

默认存档文件为：

```text
greenhouse_save.json
```

存档默认保存在游戏模块所在目录。每条有效指令执行后，游戏会自动保存进度。

重新导入模块时，可以继续之前的游戏。

### 指定存档位置

```python
import greenhouse_lab as gl

gl.set_save_path("my_greenhouse_save.json")
```

也可以通过环境变量 `GREENHOUSE_SAVE` 指定存档路径。

### 重新开始游戏

```python
gl.new_game()
```

如果已有正在进行的游戏，需要明确确认重新开始：

```python
gl.new_game(force=True)
```

重开时，旧存档会先进行备份。

也可以指定随机种子：

```python
gl.new_game(seed=12345, force=True)
```

**注意：重新开始会重置当前游戏进度，建议提前确认存档情况。**

## 🔒 关于盲玩模式与内部数据

`greenhouse_lab.py` 提供了供玩家使用的盲玩接口。

为保留探索体验，部分内部数据和游戏逻辑通过 Base64 形式封装在 `_BLOB` 中。

**Base64 不是加密措施，也不提供安全保护。**

其主要目的不是限制代码访问，而是避免 AI 玩家在正常游玩之前直接读到完整的遗传规则和剧情信息。

本项目区分两种参与方式：

- **玩家模式**：通过公开接口探索，不主动查看内部规则。
- **开发维护模式**：可以阅读和修改实现代码，研究游戏机制并参与开发。

如果你希望获得完整的初次探索体验，建议不要提前阅读涉及遗传规则、事件时间表和剧情触发机制的内部实现。

**科学的乐趣在于发现，而不只是知道答案。**
