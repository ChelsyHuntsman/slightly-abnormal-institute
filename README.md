# 不太正常的植物研究所（The Slightly Abnormal Botanical Institute）

城北一片老苗圃里的植物研究所：四座温室、一间育苗室、一间组培室、一个种子库、一群各忙各的同事，还有一些「不太正常」的植物。
你是新来的研究员。播种、照料、授粉、采种、观察、记录——遗传规律藏在植物身上，要你自己用杂交和统计把它们找出来。

这是给 AI Agent 玩的文字模拟游戏，所有操作都通过 `cmd("指令")` 完成。为柏郁青写的。

> ⚠️ **剧透提醒**：README 后半部分（「内部规则」以后）、`genetics.py` 和 `content.py` 写着完整的遗传表和剧情。只想玩的话拿 `greenhouse_lab.py` 就够了。

## 快速开始

```python
import greenhouse_lab as gl
print(gl.cmd("help"))
print(gl.cmd("talk wen; status; lots"))
print(gl.cmd("sow S001 10; sow S002 10"))
print(gl.cmd("end"))            # 结束今天
```

- Python 3.10+，只用标准库。
- 第一次 `import` 自动开局（随机种子）。指定种子：`gl.new_game(seed=42, force=True)`。
- 存档默认是同目录下的 `greenhouse_save.json`，每条有效指令执行完就保存；重新 `import` 接着玩。
- 换存档位置：`gl.set_save_path("某处/存档.json")`，或环境变量 `GREENHOUSE_SAVE`。

```

content.py          内容：属与品系、温室、物资、NPC、对话、事件、文件、异常现象

build.py            打包
tests/
  test_greenhouse.py  功能测试
  bots.py             自动玩家：育种狂热型 / 收藏癖型 / 经营稳健型
  playtest.py         多种子长周期试玩 + 数据一致性检查
```

`greenhouse_lab.py` 里的 base64 **不是加密**，只是为了让 AI 玩家不会不小心看到答案。改了源文件后运行 `python3 build.py`。

## 一天怎么过

每天 8 小时工时（08:00—16:00）。动作花时间，`end` 结束一天，夜里植物生长、世界推进，早上告诉你发生了什么。

| 做什么 | 指令 | 时间 |
|---|---|---|
| 看全局 | `status`、`zones`、`zone A`、`plants [区/品系/批次/dead/all]`、`people` | 0 |
| 看一株的档案 | `plant P0012`（来源、祖先、健康、每个性状最近一次观察、标记、日记、经历） | 0 |
| 谱系 | `tree P0012`（往上四代，开放授粉的父本显示为不明） | 0 |
| 观察 | `observe P0012` / `observe A`（只记录**当前阶段、当前环境下**看得见的性状） | 5 分/株 |
| 分子检测 | `test P0012 R`（单个位点，耗试剂；有些位点没有标记） | 60 分 |
| 播种 | `sow S001 10 [区]`（默认育苗室） | 10+2 分/粒 |
| 照料 | `water`、`feed`、`prune`、`repot <株> S/M/L`、`treat <株/区> soap/bio/fungicide/pesticide`、`move` | 3~30 分 |
| 繁殖 | `cut`（扦插/分株）、`culture <株> [double]`（组培 / 秋水仙素加倍）、`transplant F001` | 20~45 分 |
| 杂交 | `cross <母本> <父本或花粉>`、`self`、`bag`、`pollen`、`harvest` | 15~30 分 |
| 环境 | `set A temp 22`、`set A light 10`（要补光灯组）、`set A radio on`、`set A nightbreak on` | 5 分 |
| 记录 | `lots`、`lot S040`、`exp`、`exp X003`、`ratio X003 花色`、`select X003 花色 淡紫`、`mark`、`note` | 0 |
| 图鉴 | `catalog`、`catalog traits`、`catalog anomalies`、`catalog lines` | 0 |
| 收藏 | `keep`、`collection`、`diary`、`name`、`tag`、`press` | 0~30 分 |
| 人 | `talk wen`、`ask su 编号`、`give <株> <人>`、`write lin` | 10~30 分 |
| 经营 | `shop`、`buy soil 20`、`upgrade lamp`、`report X003`、`report anomaly noc`、`supplies` | 0~120 分 |
| 时间 | `end`、`end 3`（最多 7 天，期间没人照料） | — |

植株编号可以只写数字（`plant 12`）。中文命令也可以（`观察 A`、`杂交 P0013 P0012`）。批量指令用 `;` 隔开，一次最多 10 条；有事需要你决定或一天结束时自动停下。

### 记录系统

- **个体**：每株有永久编号、来源批次、杂交编号、母本、父本、世代、祖先品系、完整经历（发芽、开花、授粉、检测、搬动、死亡……）。死掉的、没发芽的也保留档案（`plants dead`）。
- **批次**：每次采种入库一个批次，记录来自哪个杂交、母本、父本、世代标签（F1、F2、回交、开放授粉、远缘 F1）、剩余粒数、活力。
- **实验**：每次授粉一个编号，状态从「等待坐果」到「坐果」「失败」「已采种」「错过采种期」。
- **统计**：`ratio` 只用**你记录过**的后代表型做分类计数，和 1:1、3:1、1:2:1、9:3:3:1、9:3:4、9:7、15:1 等比例做卡方检验，给出 p 值。样本少于 12 株会提醒。
- **存疑**：实习生可能把育苗盘的标签插反。被影响的苗会标「来源存疑」，`relabel` 改记录（旧记录保留在经历里），`clear` 去掉存疑标记。
- **图鉴**：每种性状表现第一次被观察到的时间和植株；异常现象从「观察到」到「解释了」。

### 收藏温室

`keep` 把任何一株搬进私人收藏温室（12 格）。不需要稀有。那里有人帮忙浇水施肥，病虫害也少。
可以取名、贴标签、写日记；`collection` 像一本植物日记，列出每一株的来历、最近的样子、它经历过的重要日子、你写的话。
收藏的植物死了会自动压成标本，日记和标签一起夹进标本册。也可以主动 `press`——没发芽的、失败的，都可以留下。
收藏温室没有任何数值加成。唯一的「功能」是开放日可以拿它出来展示。

### 经营

开局 3000 元、声誉 30。每两周拨款 800 元，加上这两周写的报告奖励。暖气、制冷、补光按天扣钱（冬天贵）。
物资（培养土、花盆、营养液、隔离袋、试剂、培养基、秋水仙素……）要买；设备（便携收音机、夜间补光定时器、超净台、花粉冷冻盒、滴灌、种子库扩容、补光灯组）要攒钱。
第 42 天有年度评估：看报告、解释的异常、图鉴、植株健康和账面。结果影响拨款；结果太差，收藏温室会被划走一半。

## 内部规则（剧透）

### 遗传系统（`genetics.py`）

- 24 个位点分布在 8 条染色体上，各有位置（cM）。减数分裂按 Haldane 映射函数在相邻位点间发生交换，所以**连锁是真的**：比如条纹斑 V 和叶面斑点 S 只隔 5 cM，测交会看到约 5% 的重组型。
- **花色**：P（色素合成）上位于 R（红色强度，不完全显性）和 Y（黄色素）。pp 白花（有 Y 则奶油白）；P_ 时 RR 深红、Rr 粉红、rr 淡紫，有 Y 变成朱橙、杏色、柠檬黄。低温下花青素加深（淡紫偏蓝紫）。
- **碎色**：P 位点上的 pm 是转座子插入等位。体细胞回复 → 白花上的红色条纹，每次开花条纹数都不同；生殖细胞里约 3% 回复成 P，后代会冒出正常红花。
- **叶片**：G（叶绿素，gg 黄绿）、V（vv 乳白条纹，弱光下看不清）、S（显性斑点）、B（b 绿 / B 铜红 / B* 墨铜）。
- **副突变**：B*/B 杂合体里，B 在减数分裂时有 90% 被改写成 B*。墨铜 × 铜叶的 F2 几乎全墨；墨铜 × 绿叶（b）就正常 3:1。
- **质体遗传**：叶片白色嵌合扇区来自质体，只经母本传递，后代按母本比例分选（全绿、全白、嵌合）。全白苗子叶耗尽后死亡。用嵌合株当父本，后代全绿。
- **表观沉默**：香气 O 可被胁迫沉默（看起来和无香一样，但分子检测有 O）；在 10℃ 以下待满十天（春化）解除；沉默状态有一半机会传给后代。
- **数量性状**：株高由 3 个加性位点 + 矮化主效基因 + 光照、养分、盆大小、健康共同决定；耐寒、耐旱、耐阴各由 1~2 个位点控制，只有在对应的环境挑战下才看得出来。结籽数由 2 个位点 + 健康决定。
- **光周期**：F_ 是短日植物，日照 ≤ 12.5 小时、且夜里没有被光打断才开花；ff 日中性。L_ 的花苞要在长夜被一段光打断后才开放（夜断）。
- **声响应**：Au_ 的听风草在开着收音机的温室里叶片偏向声源。
- **远缘杂交**：几对「姊妹属」可以勉强杂交（成功率约 15%），F1 几乎不育；秋水仙素加倍成功后可育，自交后代与亲本完全一致（双二倍体真实遗传）。其他属之间不能杂交。
- **突变**：每位点每次减数分裂 0.05% 自发突变，只往「功能丧失」方向（显性功能等位 → 隐性），所以大多数突变藏在杂合子里，几代以后才冒出来。
- 自交不亲和的属（月下铃）自交成功率只有正常的 5%。

### 不太正常的现象

| 现象 | 解释 | 怎么证实 |
|---|---|---|
| 月下铃只在某些早上开花 | 夜断：老范巡逻时手电照过主温室 | 买夜间补光定时器，在别的温室开夜间补光，观察到花开 |
| 碎色朱点的条纹每次都不一样 | pm 转座子 | 同一株记录到两次不同条纹数，并读到林知秋笔记第 1 页 |
| 哑香丝草不香 | O 被沉默 | 分子检测有 O 但不香；在冷室待十天后重新观察到香味 |
| 听风草朝收音机歪 | Au 声响应 | 收音机开着时观察到「歪」和「不歪」两种，或读到莫博士的草稿 |
| 登记簿缺 0413—0419 | 林知秋藏起来的种子 | 拿到 D 温室钥匙，搜到花台下的铁盒 |
| 墨铜叶后代不按孟德尔分离 | 副突变 | 墨铜 × 铜叶 → F2（≥10 株）`ratio` 叶色只有墨铜一类 |
| 嵌合斑叶的白斑只跟母亲 | 质体母系遗传 | 正交、反交都做，双方后代各观察 ≥5 株叶色 |

解释了的现象可以写成报告（`report anomaly <id>`），拿声誉和经费。

**测试和试玩中发现并修好的问题**：

- 所有品系默认是短日植物（默认等位写反了），春夏几乎都不开花；默认黄色素也写反了，很多植物开出意料之外的橙花。
- 开局的成株一年生植物年龄设得太大，几天后就老死了。
- 种子库容量 40，开局就占了 34 个，采几次种就满了；扩到 80，并加了 `dump` 清理批次。
- 授粉失败要等花期结束才报告；现在三天就知道，花还开着的话可以重新授粉。
- 缺水几乎不会死，冷害又太快（香丝草春化十天就冻死了）；重新调了胁迫曲线。
- 开放日卖苗会把实验材料一起卖掉；现在只卖品系的小苗。
- 野外朱点花种群里没有耐寒基因，骆青禾要的「冷室里也能开的淡紫朱点」根本育不出来；补上了。
- 观察时「图鉴新增」出现在观察结果前面。
- 一代朱点花只结十几粒种子，F2 样本太小；提高了结籽数，`ratio` 支持合并多个实验。

## 已知问题和取舍

- 一代大约 20~25 天（播种→开花→采种），所以一个 F2 要到第 60~90 天左右。这是有意的：它应该是一件要花时间的事。
- 机器人跑两年大约要 4 分钟；存档会随植株数增长（两年约 1 MB），每条指令都会完整写一次存档。几年以后可能会感觉变慢。
- NPC 对话按顺序推进，问同一个话题第二次会重复回答。
- 异常现象的「解释」判定是写死的条件（比如副突变要求 F2 至少 10 株、只有墨铜一类）。用别的方法证明了同一件事，游戏不一定认。
- 遗传是简化的：二倍体、24 个位点、没有多倍体分离（加倍以后直接真实遗传）、没有基因剂量效应（除了 R）。
- 内容按「一年」写：第二年起季节事件、评估、进山会重复，剧情事件（D 温室、林知秋）不会重来。

## 可以继续做的方向

- 更多属和异常现象（比如只在满月前后结实的、会对某个人的声音有反应的）。
- 多倍体育种：加倍以后的同源四倍体分离。
- 谱系图导出成文字图表 / 家系表。
- 第二年以后的新剧情：林知秋的研究被重新审视、骆青禾的冷蓝 F5、迟野的第三次进山。
- 跨存档的「种子交换」：从一局游戏导出一个批次，导入另一局。
